# REFV-KG Data

This directory contains the RDF-star knowledge graphs and document manifests used in the REFV-KG study:

> *An LLM-based Framework for Constructing RDF-star Knowledge Graphs from Renewable Energy Policy Documents for Stakeholder Opinion Analysis*

The original source documents and intermediate topic-extracted text files are not redistributed in this directory.

## Directory structure

```text
data/
├─ README.md
├─ metadata/
│  ├─ all_documents_manifest.tsv
│  ├─ all_documents_manifest.ttl
│  ├─ minutes_topic_extracted_manifest.tsv
│  └─ minutes_topic_extracted_manifest.ttl
└─ rdf/
   ├─ all_documents/
   ├─ minutes_topic_extracted/
   └─ supplementary/
      └─ all_documents_en_machine_translated_2026-07-20.nq
```

## RDF datasets

### `rdf/all_documents/`

This dataset was constructed by applying triple and opinion extraction directly to the full text of 523 documents, without topic extraction.

| Region | Number of documents |
|---|---:|
| Akita | 66 |
| Hokkaido | 151 |
| Shimane | 36 |
| Yamagata | 270 |
| **Total** | **523** |

The collection contains the following document types.

| Document type | Number of documents |
|---|---:|
| Parliamentary records | 202 |
| Administrative materials | 91 |
| News reports | 84 |
| Web articles | 66 |
| Review-board materials | 28 |
| Business-operator materials | 23 |
| Environmental-assessment materials | 11 |
| Materials from citizen or resident organizations | 9 |
| Public-relations materials and publications | 8 |
| Other | 1 |
| **Total** | **523** |

The subdirectories retain the regional organization used during data construction. Each TriG file corresponds to one source document and uses a named graph for that document.

### `rdf/supplementary/all_documents_en_machine_translated_2026-07-20.nq`

This optional N-Quads file contains English literals generated by machine translation from the Japanese RDF data in `rdf/all_documents/`. It includes translated labels, comments, opinion content, and supporting source text, while preserving the named graph IRIs of the all-document dataset.

Load this file into the same RDF dataset as `rdf/all_documents/` and `metadata/all_documents_manifest.ttl` to enable language-specific retrieval in Japanese and English. It supplements the all-document dataset and is not intended to be used as a standalone knowledge graph.

The English translations were generated automatically and have not been fully reviewed by human translators. They may contain translation errors or terminology inconsistencies.

### `rdf/minutes_topic_extracted/`

This dataset represents the parliamentary-record condition in which GPT-5.2 was first used to extract wind-power-related text spans. The production topic-extraction run was conducted on July 18, 2026, using the default OpenAI API settings for temperature, seed, and other parameters.

The processing counts are:

- 202 parliamentary records were provided as input.
- Topic-relevant text was extracted from 196 records.
- RDF files were generated for 193 records.
- 192 RDF files contain at least one extracted causal triple.
- One RDF file contains document metadata but no extracted causal triple.
- Three records with extracted text did not produce RDF files.
- Six input records contained no text matching the target topic.

The directory therefore contains 193 TriG files. The files cover 174 records from Yamagata and 19 records from Hokkaido.

The 202 parliamentary records are also included in `rdf/all_documents/`, where their full text was processed without topic extraction. The two conditions can therefore be compared to analyze the effect of topic extraction.

## Document manifests

The `metadata/` directory provides mappings between source-document information, named graph IRIs, and RDF files.

- `all_documents_manifest.tsv`: tabular manifest for all 523 documents.
- `all_documents_manifest.ttl`: RDF representation of the all-document manifest.
- `minutes_topic_extracted_manifest.tsv`: tabular manifest for the 193 generated parliamentary-record RDF files.
- `minutes_topic_extracted_manifest.ttl`: RDF representation of the topic-extracted manifest.

The TSV files are intended for human inspection and statistical processing. The Turtle files provide the corresponding document metadata in RDF for integration and querying.

### TSV columns

| Column | Description |
|---|---|
| `都道府県名` | Prefecture or region associated with the document |
| `資料種別` | Document type |
| `元のTSVファイル名` | Name of the source relation table used during processing |
| `input_file` | Original input filename |
| `graph` | Named graph IRI assigned to the document |
| `output_file` | Corresponding TriG filename |
| `json_file` | Intermediate JSON path recorded by the construction process |
| `保存されていたフォルダ名` | Original source-folder information |

The intermediate JSON files referenced in `json_file` are not included in this data release. The field is retained as processing provenance.

## RDF representation

The RDF data use RDF-star for statement-level links among causal triples, opinions, stakeholders, and supporting source text. Each source document is represented as a named graph in a TriG file.

The principal namespaces are:

```sparql
PREFIX rdf:  <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX kg:   <https://kozaki-lab.jp/REFV-KG/data/>
PREFIX cls:  <https://kozaki-lab.jp/REFV-KG/class/>
PREFIX prop: <https://kozaki-lab.jp/REFV-KG/prop/>
```

The causal predicates used in the study are:

- `prop:cause`
- `prop:effect`
- `prop:countermeasure`

Queries used for the paper's analyses are available in the repository's `queries/` directory.

## Loading the data

To run the example queries and the analysis queries used in the paper, load one manifest and its corresponding document-level RDF files into the same RDF dataset in a triple store that supports RDF-star and named graphs.

- Load the Turtle manifest into the default graph.
- Load the corresponding TriG files into the same RDF dataset.
- Each TriG file already specifies its document-level named graph IRI; no graph IRI needs to be assigned manually when loading it.
- The two processing conditions should normally be loaded into separate RDF datasets.
- To add English machine-translated literals to the all-document dataset, also load `rdf/supplementary/all_documents_en_machine_translated_2026-07-20.nq` into that dataset.

The recommended configurations are:

| RDF dataset | Default graph | Named graphs |
|---|---|---|
| Topic-extracted parliamentary records | `metadata/minutes_topic_extracted_manifest.ttl` | All TriG files under `rdf/minutes_topic_extracted/` |
| All documents without topic extraction | `metadata/all_documents_manifest.ttl` | All TriG files under `rdf/all_documents/` |
| All documents with optional English translations | `metadata/all_documents_manifest.ttl` | All TriG files under `rdf/all_documents/`, plus `rdf/supplementary/all_documents_en_machine_translated_2026-07-20.nq` |

The manifest in the default graph describes each source document and provides its named graph IRI. The document-level RDF statements are stored in the named graphs specified by the TriG files. A query can therefore select document graphs through metadata in the default graph and inspect their contents using `GRAPH ?g`.

For example, the parliamentary-record graphs in the all-document dataset can be selected and queried as follows:

```sparql
PREFIX kg:   <https://kozaki-lab.jp/REFV-KG/data/>
PREFIX prop: <https://kozaki-lab.jp/REFV-KG/prop/>

SELECT ?g ?s ?p ?o
WHERE {
  # The manifest is loaded in the default graph.
  ?g prop:documentType kg:documentType_CouncilMinutes .

  # Each document's statements are stored in its named graph.
  GRAPH ?g {
    ?s ?p ?o .
  }
}
```

Language tags can then be used to select Japanese or English literals. For example:

```sparql
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>

SELECT ?resource ?label
WHERE {
  GRAPH ?g {
    ?resource rdfs:label ?label .
    FILTER(LANG(?label) = "en")
  }
}
LIMIT 100
```

In this README, an "RDF dataset" means a dataset or repository managed by the triple store; it does not mean the GitHub repository.

## Scope and limitations

- The RDF was generated using LLM-based extraction and may contain extraction, normalization, or classification errors.
- The current class organization is preliminary and does not constitute a complete renewable-energy ontology.
- The topic-extracted dataset mainly targets wind-power-related content.
- A generated RDF file does not necessarily contain a causal triple, as demonstrated by the one metadata-only file in the topic-extracted dataset.
- The English literals in the supplementary N-Quads file were generated by machine translation and have not been fully reviewed by human translators.
- Source filenames and folder information are provided for traceability. The original documents remain subject to the terms and rights of their respective providers.
- See the repository root for applicable license and citation information.

## 日本語概要

このディレクトリでは、論文で構築・分析した2種類のRDF-starデータと、抽出元文書との対応表を公開しています。

- `rdf/all_documents/`：523文書の全文を、トピック抽出なしで処理したデータ
- `rdf/minutes_topic_extracted/`：202件の議事録を対象にトピック抽出を行った後のデータ
- `rdf/supplementary/all_documents_en_machine_translated_2026-07-20.nq`：全文書版の日本語リテラルを英語へ機械翻訳した補足データ
- `metadata/`：抽出元文書、名前付きグラフIRI、TriGファイルの対応表

議事録202件のうち、196件からトピック関連テキストが抽出されました。193件についてRDFファイルが生成され、そのうち192件には1件以上の因果トリプルが含まれます。残る1件は文書メタデータのみで、抽出トリプルは0件です。

元文書およびトピック抽出後の中間テキストは、このディレクトリでは再配布していません。TSVとTurtleのマニフェストによって、公開RDFと抽出元文書情報の対応を確認できます。

### トリプルストアへの格納方法

サンプルクエリおよび論文の分析クエリを実行するには、対応するマニフェストと文書単位のRDFを、トリプルストア内の同じRDFデータセットに格納します。

- Turtle形式のマニフェストをデフォルトグラフに格納します。
- 対応するTriGファイル群を同じRDFデータセットに格納します。
- 各TriGファイルには文書単位の名前付きグラフIRIが既に記述されているため、読み込み時にグラフIRIを別途指定する必要はありません。
- トピック抽出後の議事録データと、トピック抽出なしの全文書データは、原則として別々のRDFデータセットに格納します。
- 全文書版で日本語・英語を言語タグによって検索する場合は、英語機械翻訳ファイルも全文書版と同じRDFデータセットに追加します。

推奨する組み合わせは次のとおりです。

| RDFデータセット | デフォルトグラフ | 名前付きグラフ |
|---|---|---|
| トピック抽出後の議事録 | `metadata/minutes_topic_extracted_manifest.ttl` | `rdf/minutes_topic_extracted/`以下の全TriGファイル |
| トピック抽出なしの全文書 | `metadata/all_documents_manifest.ttl` | `rdf/all_documents/`以下の全TriGファイル |
| 英語機械翻訳を追加した全文書 | `metadata/all_documents_manifest.ttl` | `rdf/all_documents/`以下の全TriGファイル、および`rdf/supplementary/all_documents_en_machine_translated_2026-07-20.nq` |

デフォルトグラフのマニフェストから対象文書のグラフIRIを取得し、`GRAPH ?g`を用いて各文書のRDFを検索できます。ここでいう「RDFデータセット」はトリプルストアが管理するデータセットまたはリポジトリを指し、GitHubリポジトリを意味しません。

英語機械翻訳ファイルは、全文書版と同じ名前付きグラフIRIを保持しています。全文書版と併せて読み込むことで、`LANG(?label) = "ja"`または`LANG(?label) = "en"`のように言語タグを指定した検索が可能になります。英訳は機械翻訳によって生成され、人手による完全な確認は行っていないため、翻訳誤りや用語の揺れが含まれる可能性があります。
